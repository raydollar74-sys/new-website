# Huanqiu Precious Metal — clean static website

A hand-written clone of the site in **plain HTML, CSS and JavaScript only**.
No Node.js, no framework, no build step.

## Contents

- `*.html` — 22 pages (home, about, 8 service pages, industries, process,
  sustainability, gallery, contact, blog, blog reader, 3 legal pages, sitemap, 404)
- `css/style.css` — the single hand-written stylesheet
- `js/main.js` — menus, hero slideshow, counters, assay modal, gallery filters,
  contact form (EmailJS), WhatsApp button
- `js/blog.js` — loads the blog from the company's public Blogger API
- `fonts/` — Inter webfont files
- images and videos used by the pages (copied from the repository's `public/`)

## Hosting

Upload this folder's contents to any static host (cPanel, GitHub Pages,
Netlify, Cloudflare Pages…). `index.html` is the home page.
